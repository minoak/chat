#### 1. 보석 조달 결정
희귀 보석 광산 계약
```
코델리아: "에메랄드 광산 독점권이 나왔어. 근데 가격이 좀..."
<StockChart:LUXORIA />

→ [독점권 확보 - 대규모 투자]
→ [부분 지분만 - 리스크 분산]
→ [포기 - 다른 기회를 기다림]
```

결과:
- 독점 + 성공 → LUXORIA 주가 급등, 보석 가격 통제권
- 독점 + 실패 → 대규모 손실
- 부분 지분 → 안정적 수익

#### 2. 브랜드 경쟁
GUCCIEL(천사의 직물)과의 경쟁
```

"가만 둘 거야?!"

→ [정면 승부 - 신규 컬렉션 출시]
→ [협력 제안 - 콜라보레이션]

```

#### 3. 가문 문제

→ [무시하자고 한다]

→ [저가 라인 반대 - 가문 명예]
→ [저가 라인 찬성 - 현실적 판단]
→ [중간 가격대 제안 - 절충안]
