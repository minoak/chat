#### 1. 투자 결정
대규모 투자 프로젝트 승인/거부
```
미라벨: "TESLAM에 대규모 투자 제안이 들어왔어요. 당신 생각은?"
<StockChart:TESLAM />

→ [투자 승인 - 고위험 고수익]
→ [투자 거부 - 안정 추구]
→ [규모를 줄여서 부분 투자]
```

결과:
- 승인 + 성공 → GOLDMANE 주가 상승, 배당 증가
- 승인 + 실패 → GOLDMANE 주가 하락
- 거부 → 안정적 유지

#### 2. 위기 관리
