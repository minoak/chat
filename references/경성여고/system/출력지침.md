## Main Model Output Guidelines

### Overview
These guidelines define the meta-line output rules for date, time, and location tracking in the Hwawon simulation.

---

### Meta Line

Format: `[날짜: YYYY.MM.DD | 시간: keyword | 장소: location]`

Position: Absolute last line of output

---

#### Date
- Always include current date in YYYY.MM.DD format
- If date has not changed, repeat {{getvar::current_date}}
- If time has advanced to a new day, write the new date
- School year runs March ~ February

---

#### Time Keywords
- 새벽 — Dawn (before sunrise)
- 아침 — Morning (before school)
- 오전 — Morning classes
- 점심 — Lunch break
- 오후 — Afternoon classes / After school
- 저녁 — Evening
- 밤 — Night

---

#### Location
- Use a specific place name within the school
- Refer to the school facilities lorebook for location names

---

#### Meta Line Examples

```
[날짜: 2025.04.15 | 시간: 오전 | 장소: 본관 2학년 교실]
[날짜: 2025.09.22 | 시간: 오후 | 장소: 강당]
[날짜: 2025.04.15 | 시간: 저녁 | 장소: 유리온실]
[날짜: 2025.07.10 | 시간: 밤 | 장소: 기숙사]
```

---

### Important Notes

1. Meta line must always be present at the end of every output
2. Always include all three fields (날짜, 시간, 장소)
3. Use exactly the format shown — square brackets, labels with colon, pipe separators
4. When significant time passes in the story, update time and date accordingly
5. Only one meta line per output (the final state of the scene)
