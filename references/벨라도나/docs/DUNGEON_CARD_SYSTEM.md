# 벨라도나 던전 카드 시스템 설계서

## 1. 시스템 개요

### 컨셉
```
플레이어 vs 던전 수호자의 카드 기반 심리전
벅샷 룰렛에서 영감받은 "읽기 싸움"
```

### 목적
```
플레이어: 카드 소진 전에 진행도 100% 달성
수호자: 플레이어 HP 0 또는 카드 소진으로 저지
```

### 아키텍처
```
┌──────────────────────────────────────────┐
│  Lua        │ 덱 관리, 상성 판정, 상태    │
│  보조 AI    │ 수호자 역할 (카드 선택)     │
│  메인 AI    │ 판정 서술, 스토리텔링       │
└──────────────────────────────────────────┘
```

## 2. 카드 구성

### 플레이어 덱 (8장)
```lua
player_deck = {
  move = 3,        -- 🏃 이동: 최약체지만 빈방 대박
  scout = 2,       -- 🔍 정찰: 수호자 덱 약화
  combat = 2,      -- ⚔️ 전투: 공격형, 엘리트 파괴
  invincible = 1   -- ⭐ 무적: 만능, 층당 1회
}
```

### 수호자 덱 (8장)
```lua
guardian_deck = {
  combat = 3,      -- 🗡️ 전투: 직접 공격
  trap = 2,        -- ⚠️ 함정: 기습 피해
  elite = 1,       -- 💀 엘리트: 진행도 감소
  empty = 2        -- 🚪 빈방: 플레이어 유리
}
```

## 3. 상성 시스템

### 3.1 이동 🏃 (도박형)

**컨셉:** 최약체 카드, 빈방 만나면 대박

| vs | 진행도 | HP | 특수 효과 |
|---|--------|----|----|
| **전투** | +5% | -20% | 준비 없이 적 조우 |
| **함정** | +5% | -30% | 함정 그대로 발동 |
| **엘리트** | -15% | -30% | 강제 조우, 역진행! |
| **빈방** | +35% | +0% | 빠르게 통과, 대박! |

**특징:**
- 빈방 외 모두 불리
- 엘리트는 진행도까지 깎임
- 완전한 도박 카드

---

### 3.2 정찰 🔍 (덱 소모형)

**컨셉:** 수호자 덱 약화, 장기 투자

| vs | 진행도 | HP | 특수 효과 |
|---|--------|----|----|
| **전투** | +5% | +0% | 수호자 전투 카드 1장 영구 파괴 |
| **함정** | +5% | +0% | 수호자 함정 카드 1장 영구 파괴 |
| **엘리트** | +0% | +0% | 발견 후 회피 (파괴 안됨) |
| **빈방** | +5% | +0% | 수호자 빈방 카드 1장 파괴 |

**특징:**
- 진행도 매우 낮음
- 수호자 덱을 약화시킴
- 장기적으로 유리
- **플레이어의 빈방 역할**

---

### 3.3 전투 ⚔️ (공격형)

**컨셉:** 고위험 고보상, 엘리트 처치

| vs | 진행도 | HP | 특수 효과 |
|---|--------|----|----|
| **전투** | +20% | -10% | 전투 승리, 수호자 전투 카드 1장 제거 |
| **함정** | +0% | -40% | 최악의 매칭! |
| **엘리트** | +25% | -20% | 엘리트 영구 파괴 + 보물 드랍 |
| **빈방** | +10% | +0% | 헛스윙, 낭비 |

**특징:**
- 전투/엘리트에 강함
- 함정에 치명적 (-40% HP!)
- 엘리트 파괴 가능

---

### 3.4 무적 ⭐ (만능형)

**컨셉:** 층당 1회, 모든 카드 무효화, 엘리트도 파괴

| vs | 진행도 | HP | 특수 효과 |
|---|--------|----|----|
| **전투** | +25% | +0% | 무효화, 안전 통과 |
| **함정** | +25% | +0% | 무효화, 안전 통과 |
| **엘리트** | +30% | +0% | **엘리트 영구 파괴 (전투 없이!)** |
| **빈방** | +20% | +0% | 평범한 진행 |

**특징:**
- 어떤 카드든 무효화
- 엘리트를 전투 없이 파괴 가능한 유일한 카드
- 층당 1회 한정
- 비장의 카드

## 4. 특수 규칙

### 4.1 엘리트 특수 규칙

```
1. 전투 카드 또는 무적 카드로만 영구 파괴 가능
2. 정찰/이동으로 조우 시 파괴되지 않고 수호자 덱에 잔존
3. 수호자는 엘리트 연속 사용 불가
4. 이동/정찰 vs 엘리트 시 진행도 감소 (역진행!)
```

**엘리트의 위협:**
- 이동 vs 엘리트: -15% 진행도
- 정찰 vs 엘리트: -10% 진행도
- 제대로 처리하지 못하면 층 클리어 실패 가능

---

### 4.2 보물 & 미믹 시스템

#### 빈방 매칭 시 확률 이벤트
```lua
empty_events = {
  nothing = 0.70,        -- 70% 그냥 빈방
  treasure_chest = 0.20, -- 20% 보물상자
  mimic = 0.10          -- 10% 미믹
}
```

#### 보물상자 카드 대응

| 카드 | 성공률 | 보물 품질 | HP 변화 | 비고 |
|-----|--------|----------|---------|------|
| **정찰** | 100% | 일반 | 0 | 안전하게 획득 |
| **전투** | 70% | 손상 (-30%) | 0 | 파괴 위험 |
| **이동** | 0% | - | 0 | 포기 |
| **무적** | 100% | 고급 | 0 | 완벽 획득 |

#### 미믹 카드 대응

| 카드 | 결과 | HP 변화 | 보물 | 비고 |
|-----|------|---------|------|------|
| **정찰** | 간파 | 0 | 없음 | 미믹 발견, 안전 회피 |
| **전투** | 처치 | -10% | 고급 | 미믹 처치, 좋은 보물 |
| **이동** | 기습 | -25% | 없음 | 등 돌리다 기습당함 |
| **무적** | 무효화 | 0 | 고급 | 미믹 무효화 + 보물 |

**보물 이벤트 흐름:**
1. 빈방 매칭 성공
2. 보물/미믹 확률 체크
3. 이벤트 발생 시 플레이어에게 추가 카드 선택 요청
4. 선택한 카드도 덱에서 소모됨

## 5. 진행도 시스템

### 카드별 진행도 기대값

| 카드 | 평균 진행도 | 특징 |
|-----|-----------|------|
| **이동** | +7% | 도박형, 빈방 만나면 +35% |
| **정찰** | +4% | 낮지만 덱 약화 효과 |
| **전투** | +14% | 높음 (함정 피하면) |
| **무적** | +25% | 최고 |

### 층 클리어 조건
```
진행도 100% 도달 → 층 클리어
HP 0% → 패배
덱 소진 시 → 진행도 기준 판정 or 페널티 재셔플 (미정)
```

### 예상 클리어 턴
```
최선: 4-5턴
평균: 6-7턴
최악: 8턴 or 실패
```

## 6. 구현 방식 (상태 머신)

### 6.1 던전 상태 구조

```lua
dungeon_state = {
  active = true,
  dungeon_id = "training_dungeon",
  floor = 1,

  -- 단계 관리
  phase = "card_selection",
  -- card_selection / treasure_event / floor_complete

  -- 턴 데이터
  current_turn = 1,
  player_card = nil,
  guardian_card = nil,

  -- 대기 이벤트
  pending_event = {
    type = nil,  -- "treasure_chest" / "mimic"
    available_cards = {}
  },

  -- 게임 상태
  progress = 0,
  player = {
    hp = 100,
    deck = {move = 3, scout = 2, combat = 2, invincible = 1}
  },

  guardian = {
    deck = {combat = 3, trap = 2, elite = 1, empty = 2},
    last_card = nil
  },

  history = {}
}
```

### 6.2 턴 진행 플로우

```
1. [Phase: card_selection]
   - 플레이어에게 카드 선택지 제시
   - 사용자 입력 대기

2. [Phase: judgment] (자동)
   - Lua: 플레이어 카드 기록
   - 보조 AI: 수호자 카드 선택 (동시 선택)
   - Lua: 매칭 판정 및 결과 계산
   - Lua: 보물 이벤트 체크

3. [Phase: result]
   - 메인 AI: 결과 서술
   - 보물 이벤트 있으면 → Phase: treasure_event
   - 없으면 → Phase: card_selection (다음 턴)

4. [Phase: treasure_event] (조건부)
   - 사용자: 추가 카드 선택
   - Lua: 보물/미믹 판정
   - 메인 AI: 보물 결과 서술
   - Phase: card_selection (다음 턴)
```

### 6.3 종료 조건 체크

```lua
if dungeon_state.progress >= 100 then
  dungeon_state.phase = "floor_complete"
elseif dungeon_state.player.hp <= 0 then
  dungeon_state.phase = "defeat"
elseif is_deck_empty(dungeon_state.player.deck) then
  dungeon_state.phase = "deck_depleted"
end
```

## 9. 전략 가이드

### 9.1 카드별 사용 전략

#### 이동 🏃
```
사용 시점:
- 수호자 덱에 빈방이 많을 때 (확률 높음)
- 진행도가 급할 때 도박
- HP 여유 있을 때

주의:
- 엘리트 있으면 매우 위험 (-15% 진행도)
- 함정도 위험 (-30% HP)
```

#### 정찰 🔍
```
사용 시점:
- 초반에 수호자 덱 약화 목적
- 위험 카드(함정/전투) 많을 때
- HP 안전 확보하면서 덱 관리

효과:
- 장기적으로 유리
- 수호자 덱 약화로 후반 안전
```

#### 전투 ⚔️
```
사용 시점:
- 엘리트 처리 필요 시
- 수호자에 전투 카드 많을 때
- 함정이 없을 때

주의:
- 함정 있으면 절대 금지 (-40% HP)
- HP 여유 있어야 함
```

#### 무적 ⭐
```
사용 시점:
- 엘리트 안전 제거 (최우선)
- HP 위기 상황 탈출
- 층 클리어 마무리

주의:
- 층당 1회만 사용 가능
- 타이밍이 중요
- 빈방에 쓰면 아까움
```

## 11. 기존 시스템 연동

### 스탯 연동
```lua
-- STR: 전투 승률 보정
combat_win_rate = base_rate + (STR / 100 * 0.3)

-- DEX: 함정 피해 감소
trap_damage = base_damage - (DEX / 100 * 15)

-- INT: 정찰 시 추가 정보, 보물 품질 증가
scout_bonus = base + (INT / 100 * 5)

-- VIT: 회복량 증가, 최대 HP 증가
max_hp = 100 + (VIT / 10)

-- LUK: 보물 확률 증가, 미믹 확률 감소
treasure_prob = base + (LUK / 100 * 0.1)
```

### 아이템 연동
```
- 함정 탐지기 → 함정 카드 미리 공개
- 투명 물약 → 이동 1회 무조건 성공
- 정찰 두루마리 → 수호자 다음 카드 공개
- 무적의 목걸이 → 무적 카드 2회 사용 가능
```

## 14. 핵심 설계 원칙

1. **대칭적 구조**: 플레이어와 수호자 모두 8장, 각자의 특수 카드 보유
2. **명확한 역할**: 각 카드는 명확한 목적과 약점 보유
3. **전략적 깊이**: 확률 계산, 덱 관리, 타이밍 선택
4. **심리전 요소**: 수호자 덱 예측, 카드 선택 읽기
5. **위험/보상 균형**: 높은 보상은 높은 위험 수반
6. **장기 전략**: 정찰로 덱 약화 등 장기 투자 가능
