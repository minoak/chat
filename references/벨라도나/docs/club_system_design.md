# 동아리 시스템 설계 문서

## 개요

캐릭터/하우스별 테마 동아리를 시스템화하여 서사와 게임플레이를 통합.
주식투자 동아리(릴리 벨리)를 첫 번째 구현 대상으로 설정.

**세계관**: 현대 + 판타지 (금융 용어 그대로 사용)

## 핵심 원칙

1. **서사 중심** - 시스템은 기록만, 드라마는 AI가 담당
2. **역할 분리** - 메인모델/보조모델/Lua 각자 역할 명확히
3. **최소 시스템** - 복잡한 자동화 없이 단순 기록
4. **틀 안의 자유** - 템플릿 구조 내에서 AI 자유 묘사

## 1. 시스템 아키텍처

### 1.1 역할 분리

```
[메인모델] ─────────────────────────────────────────
│ 스토리 서술 + 주가 데이터 출력
│ <Stock> 틀 안에서 가격/이유를 자유롭게 묘사
│
│ 예시:
│ <Stock>
│ LILY: 105G, 상승 - 대형 상단 입주 소문
│ IMP: 243G, 하락 - 광산 사고 여파
│ NEP: 98G, 급등 - 신약 승인 기대감
│ </Stock>
└───────────────────────────────────────────────────

         ↓ 데이터 전달

[보조모델] ─────────────────────────────────────────
│ 메인모델의 <Stock> 파싱
│ 적절한 장면에서 UI 트리거 출력
│ 시스템 태그 처리
│
│ 출력:
│ [Gold:0][Stock:LILY:105:+5|IMP:243:-2|NEP:98:+12]
│ <StockPanel />
└───────────────────────────────────────────────────

         ↓ 렌더링

[Lua + Display] ────────────────────────────────────
│ 데이터 저장 (ChatVar)
│ 히스토리 자동 누적
│ 호가창 자동 생성
│ UI 렌더링 (시세표, 차트, 호가창)
│ 버튼 클릭 시 거래 즉시 처리
└───────────────────────────────────────────────────
```

### 1.2 처리 구분

| 기능 | 처리 주체 | 방식 |
|------|-----------|------|
| 가격 결정 | 메인모델 | 서사 기반 자유 결정 |
| 가격 파싱 | 보조모델 | 템플릿에서 숫자 추출 |
| UI 트리거 | 보조모델 | 장면 감지 후 태그 출력 |
| 데이터 저장 | Lua | ChatVar에 기록 |
| 히스토리 | Lua | 자동 누적 (6일) |
| 호가창 생성 | Lua | 현재가 기준 자동 생성 |
| 매수/매도 | Lua | 버튼 클릭 즉시 처리 |
| 마진콜/파산 | 메인모델 | 서사로 연출 |
| 레버리지 청산 | 메인모델 | 서사로 연출 |

## 4. 거래 유형

### 4.1 현물 거래 (Lua 즉시 처리)

```
매수: Gold 차감 → 보유량 증가 → 평균매수가 계산
매도: 보유량 차감 → Gold 증가
```

### 4.2 레버리지 (포지션 기록만)

```
진입: position 슬롯에 기록
청산: 서사로 처리 (AI가 손익 묘사)
마진콜: 서사로 처리 (AI가 상황 연출 + 선택지)
```

| 배율 | 리스크 |
|------|--------|
| 2x | 손실 2배, 마진콜 -25% |
| 3x | 손실 3배, 마진콜 -17% |
| 5x | 손실 5배, 마진콜 -10% (파산 가능) |

### 4.3 선물 (포지션 기록만)

```
롱: 가격 상승에 베팅
숏: 가격 하락에 베팅
만기: 서사로 처리 (AI가 정산 장면 연출)
```

### 4.4 공매도 (포지션 기록만)

```
진입: 주식 빌려서 매도
청산: 서사로 처리
리스크: 무제한 손실 가능 (가격 무한 상승 시)
```

### 7.2 거래 처리 함수

```lua
function stockBuy(triggerId, ticker, quantity)
    local price = getState(triggerId, "stock_" .. ticker .. "_price")
    local cost = price * quantity
    local gold = tonumber(getChatVar(triggerId, "player_gold")) or 0

    if gold >= cost then
        -- Gold 차감
        setChatVar(triggerId, "player_gold", tostring(gold - cost))

        -- 보유량 증가
        local owned = tonumber(getChatVar(triggerId, "stock_" .. ticker .. "_owned")) or 0
        local avgPrice = tonumber(getChatVar(triggerId, "stock_" .. ticker .. "_avgprice")) or 0

        -- 새 평균매수가 계산
        local newAvg = ((avgPrice * owned) + (price * quantity)) / (owned + quantity)

        setChatVar(triggerId, "stock_" .. ticker .. "_owned", tostring(owned + quantity))
        setChatVar(triggerId, "stock_" .. ticker .. "_avgprice", tostring(math.floor(newAvg)))

        addChat(triggerId, "user", ticker .. " " .. quantity .. "주를 " .. price .. "G에 매수했다.")
    else
        addChat(triggerId, "user", "골드가 부족하다. (필요: " .. cost .. "G, 보유: " .. gold .. "G)")
    end
end
```

### 7.3 호가창 자동 생성

```lua
function generateOrderBook(triggerId, ticker)
    local currentPrice = getState(triggerId, "stock_" .. ticker .. "_price") or 100
    local orderBook = {asks = {}, bids = {}}

    -- 매도호가 (현재가 +1 ~ +3)
    for i = 1, 3 do
        local price = currentPrice + i
        local volume = math.random(20, 60)
        table.insert(orderBook.asks, {price = price, volume = volume})
    end

    -- 매수호가 (현재가 -1 ~ -3)
    for i = 1, 3 do
        local price = currentPrice - i
        local volume = math.random(20, 60)
        table.insert(orderBook.bids, {price = price, volume = volume})
    end

    return orderBook
end
```

### 7.4 히스토리 업데이트

```lua
function updatePriceHistory(triggerId, ticker, newPrice)
    local history = getChatVar(triggerId, "stock_" .. ticker .. "_history") or ""
    local prices = {}

    for price in history:gmatch("([^,]+)") do
        table.insert(prices, price)
    end

    table.insert(prices, tostring(newPrice))

    -- 최근 6일만 유지
    while #prices > 6 do
        table.remove(prices, 1)
    end

    setChatVar(triggerId, "stock_" .. ticker .. "_history", table.concat(prices, ","))
end
```

## 가격 출력 규칙

## 가격 변동 기준
- 스토리 이벤트와 연동하여 자연스럽게 결정
