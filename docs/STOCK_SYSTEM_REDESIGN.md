## 4. 경고 수치 시스템

### 개요
학사경고 대신 "경고 수치" 도입
- 일정 수치 이상 시 풍기위원회/선도부 로어북 활성화
- AI가 자연스럽게 상황 묘사

### 수치 구간
```
경고 수치: 0 ~ 100
├── 0~29: 정상 (로어북 비활성)
├── 30~59: 주의 (풍기위원회 관심)
├── 60~89: 경고 (선도부 조사)
└── 90+: 위험 (징계 위원회 소집)
```

### 수치 변동
| 행동 | 변동 |
|------|------|
| 내부자 거래 적발 | +15 |
| 주가 조작 적발 | +25 |
| 금지 구역 침입 | +10 |
| The Pit 발각 | +20 |
| 결투 규정 위반 | +10 |
| 시즌 경과 (무위반) | -10 |
| 교수 변호 | -15 |

### 로어북 활성화 조건
```markdown
{{#if_pure {{greater::{{getvar::warning_level}}::29}}}}
# 풍기위원회 / 선도부
(경고 수치에 따른 내용)
{{/if_pure}}
```

### Lua 구현
```lua
-- 경고 수치 증가
function addWarning(triggerId, amount, reason)
    local current = tonumber(getChatVar(triggerId, "warning_level")) or 0
    local newLevel = math.min(100, current + amount)
    setChatVar(triggerId, "warning_level", tostring(newLevel))
    log("⚠️ 경고 수치 +" .. amount .. " (" .. reason .. ") → " .. newLevel)
end

-- 경고 수치 감소
function reduceWarning(triggerId, amount)
    local current = tonumber(getChatVar(triggerId, "warning_level")) or 0
    local newLevel = math.max(0, current - amount)
    setChatVar(triggerId, "warning_level", tostring(newLevel))
end
```

## 6. 차트 디스플레이 시스템 (신규)

### 개요
별도 주식창 UI 대신, **스토리 중간에 자연스럽게 차트 출력**
- 이야기에서 특정 주식 언급 시 해당 차트 디스플레이
- 정규식 변환으로 HTML 차트 렌더링
- 기존 주식 시스템(변수, 매매)은 유지

### 동작 흐름
```
[스토리]
페니와이즈: "LILY가 요즘 좋아 보여."

[태그 출력]
<StockChart:LILY />

[정규식 변환 → 화면]
┌─ LILY (릴리상사) ─┐
│ 120G (+5) ▲      │
│ ▁▂▃▄▅▆▇ 상승세   │
└──────────────────┘
```

### 변수 구조 (종목당)

| 변수 | 예시 | 설명 |
|------|------|------|
| `stock_LILY_price` | `120` | 현재가 |
| `stock_LILY_change` | `+5` | 등락 (전일 대비) |
| `stock_LILY_history` | `"95,98,102,100,105,108,110,107,112,115,118,120"` | 월간 12개 데이터 |
| `stock_LILY_owned` | `10` | 보유 수량 |
| `stock_LILY_avg_cost` | `100` | 평균 매수가 |

### 차트 렌더링 방식
- **저장**: 월간 12개 포인트만 저장 (1년 데이터)
- **렌더링**: 포인트 사이를 랜덤 보간하여 부드러운 곡선 생성
- **장점**: 변수 크기 최소화, 자연스러운 차트, 전체 추세 유지

```
[저장] 12개 포인트
"95,98,102,100,105,108,110,107,112,115,118,120"

[렌더링] 랜덤 보간
95 → (96,97) → 98 → (99,101) → 102 → ...

[결과] 부드러운 1년 차트
▁▂▂▃▃▄▅▄▅▆▆▇
```

### 수정 필요 파일
| 파일 | 내용 |
|------|------|
| Lua | 주식 변수 구조 정의, 히스토리 관리 |
| 정규식/HTML | `<StockChart:TICKER />` → 차트 HTML 변환 |
| AUXILIARY_PROMPT_NEW.md | 차트 태그 출력 지침 추가 |
| 로어북 | 보유 종목별 조건부 활성화 |

### 태그 형식 (예정)
```
<StockChart:TICKER />     -- 단일 종목 차트
예: <StockChart:LILY />
```

## 7. 개편 방향 (2025-12-05 확정)

### 핵심 변경
- **Lua 거래 로직 제거** → 변수 저장/조회만
- **선택지 기반 투자** → AI가 상황에 맞게 선택지 생성
- **UI 버튼 제거** → 대화와 차트로 자연스러운 판단

### 시스템 흐름
```
1. 캐릭터 대화에서 주식 정보/힌트 제공
         ↓
2. <StockChart:TICKER /> 태그로 차트 출력
         ↓
3. 사용자가 차트 + 대화 맥락으로 판단
         ↓
4. AI가 선택지 제공 (매수/매도/관망)
         ↓
5. 선택 결과 → 변수 업데이트 + 결과 묘사
```

### 역할 분담
| 담당 | 역할 |
|------|------|
| **Lua** | 변수 저장/조회, 히스토리 관리 (거래 로직 X) |
| **정규식** | `<StockChart:TICKER />` → 차트 HTML |
| **AI** | 힌트 제공, 차트 태그 출력, 선택지 생성, 결과 묘사 |
| **선택지** | 기존 시스템 활용, AI가 상황에 맞게 자동 생성 |

### 예시
```
페니와이즈: "KOMAMI? 요즘 게임 쪽이 심상치 않더라고."

<StockChart:KOMAMI />
       ▁▂▃▅▆▇ ↑

┌──────────┐ ┌──────────┐ ┌──────────┐
│ KOMAMI   │ │ KOMAMI   │ │  관망    │
│ 10주 매수 │ │ 5주 매도  │ │         │
└──────────┘ └──────────┘ └──────────┘
```
