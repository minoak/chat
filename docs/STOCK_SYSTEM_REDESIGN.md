# 주식 시스템 개편 설계안

## 참고 자료
- STONKS-9800 (스팀 게임)
- Capitalism (경영 시뮬레이션)
- 1980년대 일본 버블경제 주식 시뮬레이터

## 핵심 컨셉
- Capitalism 스타일 기업 경영 참여
- 캐릭터와 연동된 스토리 기반 플레이
- UI 버튼 매매 제거 → 선택지 + 태그 기반 변수 변경
- 차트/주식창 = 순수 디스플레이 (정보 확인용)

---

## 1. 시스템 개요

### 제거된 기능
| 기능 | 상태 | 이유 |
|------|------|------|
| UI 버튼 매매 | ❌ 제거 | 스토리 몰입 방해 |
| Lua 거래 로직 | ❌ 제거 | 불필요 |
| 20개 종목 개별 거래 | ❌ 제거 | 3개 핵심 기업으로 집중 |

### 유지/변경된 기능
| 기능 | 상태 | 역할 |
|------|------|------|
| 인사이더 정보 | ✅ 유지 | 캐릭터 호감도 기반 힌트 |
| 차트/주식창 | 🔄 변경 | 디스플레이 전용 (풀 패널) |
| 종목 리스트 | 🔄 변경 | 세계관 배경 + 3개 핵심 기업 |

### 시스템 흐름
```
캐릭터: "GOLDMANE 어때?"
        ↓
<StockChart:GOLDMANE />  ← 디스플레이 (정보 확인용)
        ↓
캐릭터: "투자할래?"
        ↓
┌─────────┐ ┌─────────┐
│ 투자    │ │ 안 함   │  ← 선택지 (AI 생성)
└─────────┘ └─────────┘
        ↓
<-Stock|BUY|GOLDMANE|100-> ← 태그 → 정규식 → 변수 변경
```

## 2. Capitalism 스타일 경영 시스템

### 컨셉
- 1개 기업 집중 + 해당 캐릭터와 스토리 연동
- 경영 의사결정 → 결과 → 캐릭터 반응

### 기업-캐릭터 연결
| 기업 | 캐릭터 | 섹터 | 설명 |
|------|--------|------|------|
| GOLDMANE | 미라벨 | 금융 | 황금갈기 금고 |
| LUXORIA | 코델리아 | 럭셔리 | 사치의 성채 |
| PFIZARA | 네펜테스 | 제약 | 연금술 제약 |

### 플레이 흐름
```
주식 동아리 가입
      ↓
페니와이즈: "어떤 기업에 관심있어?"
      ↓
┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│ GOLDMANE   │ │ LUXORIA    │ │ PFIZARA    │
│ (미라벨)    │ │ (코델리아)  │ │ (네펜테스)  │
└─────────────┘ └─────────────┘ └─────────────┘
      ↓
선택한 기업의 경영 참여 시작
(해당 캐릭터와 비즈니스 파트너 관계)
      ↓
경영 의사결정 → 결과 → 캐릭터 반응
```

### 목표 (샌드박스)
- 특정 엔딩 조건 없음
- 자유롭게 경영 플레이
- **재미가 목표** (성공도 웃기고, 실패도 웃기게)

## 6. 이벤트 시스템

### 트리거 (주간 스케줄 연동)
```markdown
{{#if_pure {{equal::{{getvar::club_stock_joined}}::1}}}}
{{#if_pure {{equal::{{getvar::stock_event_pending}}::1}}}}

[
OOC: 주식 동아리 활동 중. 이번 주 경영 이벤트를 트리거하세요.
- 캐릭터가 플레이어에게 경영 안건 제시
- 선택지 제공 후 결과 태그 출력
]

{{/if_pure}}
{{/if_pure}}
```

### 성공/실패 판정 (변수 기반)
```
기본 성공률: 50%

보정 요소:
+ market_share / 10  (점유율 높으면 유리)
+ brand_value / 20   (브랜드 가치)
+ economic_cycle     (호황: +10, 불황: -10)
- debt / 100         (부채 높으면 불리)
```

### 태그 출력 형식
```
성공: <-Stock|SUCCESS|market_share+5|price+10->
실패: <-Stock|FAIL|cash-500|price-15->
매수: <-Stock|BUY|GOLDMANE|100->
매도: <-Stock|SELL|GOLDMANE|50->
```
