# 학사일정 시스템 설계

## 설계 목표

텍스트 AI 챗봇 환경에서 **턴 경제**와 **재미**를 모두 만족시키는 학사일정 시스템 구축

---

## 문제 분석

### 초기 설계의 문제점

1. **플레이어 개입 부족**
   - 버튼 2개 클릭 → 1주일 건너뛰기 → AI 요약 읽기 → 반복
   - 실제 플레이어가 하는 건 선택 2번뿐
   - "내가 뭘 했지?" 싶은 수동적 경험

2. **선택의 의미 불명확**
   - Professor Viper vs Nightshade 선택 시 체감 차이가 약함
   - "어차피 AI가 적당히 판정하겠지" → 선택이 무의미하게 느껴짐

3. **중간 과정 생략의 아쉬움**
   - 1주일을 건너뛰면 재미있는 순간들을 놓침
   - 수업 중 사건, 복도 만남, 점심시간 대화 등을 "리포트"로만 봄
   - 감정 이입이 약함

4. **반복성으로 인한 피로**
   - 매주: 선택 → 건너뛰기 → 리포트 → 주말 → 반복
   - 10주 하면 질릴 가능성 높음

### 턴 경제 분석

**1턴 = 1일 방식 (불가능)**
- 1주일 = 7턴
- 1학기(12주) = 84턴
- 1년 = 336턴
- → 플레이어가 300턴 이상 플레이할 리 없음

**1턴 = 1주 방식 (필수)**
- 1학기 = 12턴
- 1년 = 48턴
- 시험 2번, 주요 이벤트 포함해도 적당
- → **주간 단위 건너뛰기는 턴 경제상 필수**

## 해결책: 압축+확장 하이브리드 시스템

### 핵심 아이디어

```
[기본: 1턴 = 1주] ← 빠른 진행
    ↓
[중요 순간: 시간 정지] ← 깊은 플레이
    ↓
다시 주간 단위로
```

### 구체적 흐름

**일반 주차 (압축 모드)**
- 턴 1: 커리큘럼 + 라이프스타일 선택
- AI: "한 주가 지나갔다. Professor Viper의 혹독한 훈련..."
  - 1~2문단 요약 (장황하지 않게)
  - [Stat:dex+2] [Affinity:Oleander+3] 태그 발행
- → **1턴에 1주 완료**

**이벤트 주차 (확장 모드)**
- 턴 1: 커리큘럼 선택
- AI: "수요일, Professor Viper가 당신과 Oleander를 파트너로 지정했다."
- 턴 2-4: **[시간 정지]**
  - 유저와 Oleander의 자연스러운 대화
  - 여러 턴 할애 가능
- 턴 5: 다시 요약 모드
  - AI: "그 주의 나머지 시간..."
- → **중요한 순간은 여러 턴 확장**

## 핵심 메커니즘: 강제 이벤트 시스템

### 로어북 강제 발동 구조

```handlebars
@@depth 0

{{#if {{equal::{{getvar::week_of_season}}::6}}}}
{{#if {{equal::{{getvar::midterm_done}}::0}}}}

[OOC: Trigger this event as top priority]

## 중간고사 주간
- 이번 주는 중간고사 기간입니다
- 모든 일상 활동을 중단하고 시험에 집중하세요
- Do not trigger this event during sexual activity
- Between paragraphs output: <-Midterm Exam->

{{/if}}
{{/if}}
```

### 장점

1. **자동 드라마틱 타이밍**
   - AI가 알아서 중요한 순간을 확장
   - 플레이어는 자연스럽게 몰입
   - 강제 발동이므로 놓칠 일 없음

2. **예측 가능한 리듬**
   - "6주차는 중간고사구나, 준비해야겠다"
   - 전략적 선택 가능
   - 목표 의식: "시험 전까지 INT 70 달성!"

3. **선택의 의미 명확**
   - 1~5주차: Professor Viper + 범생이 모드
   - → 6주차 시험 결과에 직접 영향
   - "범생이 모드로 INT 올렸더니 시험 1등!"
   - → 체감 가능한 피드백

**1학기 (12주) 플레이 시나리오:**
- 자유 주(7주): 7턴

- 친선대회: 3~4턴
- 기말고사: 2~3턴
- **총 20~25턴으로 1학기 완료**

## 구현 요소

### 1. Lua 변수 (상태 저장)

```lua
-- 주간 선택
current_curriculum = "Professor Viper"
current_lifestyle = "사교형"

-- 학사 상태
week_of_season = 3  -- 현재 몇 주차
is_exam_week = false
midterm_done = false
final_done = false

-- 이벤트 결과
exam_score = 0
exam_rank = 0
ball_partner = ""
```

### 2. 로어북 (조건부 활성화)

**커리큘럼 효과**
```
CURRICULUM_VIPER.md
- current_curriculum == "Professor Viper" 조건
- DEX/STR 집중 성장 힌트
- 실전 암살술 중심 수업 묘사
```

**라이프스타일 효과**
```
LIFESTYLE_SOCIAL.md
- current_lifestyle == "사교형" 조건
- 카페/라운지에서 캐릭터 조우 증가
- CHA 성장 보너스
```

**강제 이벤트**
```
EVENT_MIDTERM.md
- week_of_season == 6 && midterm_done == 0
- OOC: Top priority trigger
- 시험 진행, 결과 태그 발행
```

**호감도 기반 분기**
```
EVENT_SPRING_BALL.md
- week_of_season == 3
- {{#if eglantine_affinity >= 200}}
  - Eglantine가 춤 신청
- {{#if belladonna_affinity >= 200}}
  - Belladonna가 도전적으로 제안
- 없으면 혼자 구경
```

### 3. HTML 버튼 (선택 UI)

```html
<button class="risu-trigger" data-trigger="curriculum_select">
  커리큘럼 선택
</button>
```

Lua alertSelect로 구현:
```lua
function selectCurriculum()
  local options = {
    "Professor Viper (DEX/STR 집중)",
    "Professor Nightshade (INT/CHA 집중)",
    ...
  }
  local choice = alertSelect(options)
  setvar("current_curriculum", options[choice])
end
```

## 리포트 작성 가이드라인

### 나쁜 리포트 (장황한 나열)

```
월요일에는 암살술을 배웠고, 화요일에는 독극물학을 공부했으며,
수요일에는 체력 훈련을 했고, 목요일에는...
```

### 좋은 리포트 (간결하고 강렬)

```
Professor Viper의 일주일은 혹독했다.
세 번 죽을 뻔했지만, 이제 그림자처럼 움직인다.

Oleander와의 파트너 훈련 중 뭔가 달라진 느낌.
그녀의 웃음이 조금 늘었다.

[Stat:dex+3] [Stat:str+1] [Affinity:Oleander+5]
```

**원칙:**
- 1~2문단으로 압축
- "무엇을 했는가"보다 "무엇이 변했는가" 중심
- 감정적 변화, 관계 변화 포함
- 구체적 숫자보다 느낌 전달
- 태그로 정확한 수치 처리

## 선택의 체감 강화

### 커리큘럼 차별화

| 커리큘럼 | 주 스탯 | 부 스탯 | 특징 |
|---------|--------|--------|------|
| Professor Viper | DEX +3 | STR +1 | 실전 전투, 엄격함, 위험 |
| Professor Nightshade | INT +3 | CHA +1 | 독극물/정보전, 우아함 |
| Professor Thorn | STR +3 | CON +1 | 체술/방어, 육체 강화 |
| Professor Belladonna | CHA +3 | INT +1 | 심리전/유혹, 사교술 |

### 라이프스타일 차별화

| 라이프스타일 | 효과 | 트레이드오프 |
|------------|------|-------------|
| 사교형 | 캐릭터 조우 2~3명, CHA+1 | 골드 소모 |
| 범생이 | INT+2, 시험 보너스 | 조우 없음 |
| 모험가 | 골드+아이템, 랜덤 이벤트 | 위험, 체력 소모 |
| 은둔형 | 스탯 자유 훈련, 휴식 | 조우 없음, 평범함 |

## 세션 흐름 예시

### 세션 1 (약 15~20턴)

1. **턴 1-2**: 입학, 소개, 하우스 배정
2. **턴 3**: 1주차 선택 → 요약
3. **턴 4**: 2주차 선택 → 요약
4. **턴 5-8**: **[봄 무도회 이벤트]**
   - 파트너 선택
   - 춤추며 대화
   - 관계 진전
5. **턴 9**: 4주차 선택 → 요약
6. **턴 10**: 5주차 선택 → 요약
7. **턴 11-13**: **[중간고사 이벤트]**
   - 시험 진행
   - 결과 발표
   - 성적 기반 이벤트 분기
8. **턴 14-15**: 7주차, 8주차 진행

### 세션 2 (약 15~20턴)

- 8주차 친선대회 (여러 턴)
- 9~11주차 빠르게 진행
- 12주차 기말고사 (여러 턴)
- 방학 이벤트

## 재미 요소 체크리스트

✅ **턴 경제**: 평소 빠르게, 중요 순간만 깊게
✅ **선택의 의미**: 시험/이벤트를 대비한 전략적 선택
✅ **예측 가능성**: 학사일정 보고 계획 수립 가능
✅ **드라마틱 순간**: 강제 이벤트로 확실히 경험
✅ **개인화**: 호감도/스탯에 따라 다른 전개
✅ **목표 의식**: 명확한 단기/중기 목표
✅ **체감**: 선택의 결과가 명확히 보임
